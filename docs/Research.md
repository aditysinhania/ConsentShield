# Research

ConsentShield is designed as both a product prototype and a research vehicle.

## Scope justification

Unverifiable patterns (e.g. "Only 2 left") are excluded because ground truth requires proprietary inventory data.

## Differentiator

Multimodal fusion of vision, NLP, DOM/CSS, and rules with mandatory explanations.

## Artifacts

| Path | Purpose |
|------|---------|
| `research/papers/` | Drafts / BibTeX |
| `research/notebooks/` | Exploratory analysis |
| `research/benchmark/` | Evaluation scripts |
| `research/experiments/` | Experiment configs |
| `research/datasets/` | Local dataset mirrors (ignored) |
| `research/results/` | Metrics / plots (ignored) |

## Publication path

IEEE / HCI / usable privacy venues after collecting the custom multimodal dataset and reporting precision/recall per category with human adjudication.
